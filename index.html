Creator Upload Manager
크리에이터 업로드 매니저

이 도구는 채널 운영자가 직접 제작한 쇼츠 영상을 운영자 본인이 소유·관리하는 유튜브 채널에 업로드하기 위한 내부용 프로그램입니다. 운영자의 PC에서만 실행되며, 외부 사용자에게 제공되는 서비스가 아닙니다.

주요 기능

  • 운영자가 만든 영상 파일을 YouTube Data API(videos.insert)로 업로드
  • 제목·설명·공개 범위·아동용 여부·AI 생성 콘텐츠 표시(합성 미디어 공개) 설정
  • 일부 채널의 맞춤 썸네일 설정(thumbnails.set)

Creator Upload Manager (English)

This is an internal tool used by a channel operator to upload short videos they produced themselves to YouTube channels that the operator owns or manages. It runs only on the operator's own computer and is not offered to the public. It uses the YouTube Data API to upload videos and set their title, description, privacy status, made-for-kids flag, altered/synthetic content disclosure, and (for some channels) a custom thumbnail.
