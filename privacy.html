개인정보처리방침

시행일: 2026년 9월 28일 · 대상: "Creator Upload Manager(크리에이터 업로드 매니저)"(이하 "본 도구")

1. 이용하는 정보

본 도구는 Google OAuth를 통해 운영자가 허용한 유튜브 채널에 대해 다음 권한만 사용합니다.

  • youtube.upload — 영상 업로드 및 업로드한 영상의 정보(제목·설명·공개 범위 등) 설정
  • youtube.readonly — 연결된 채널이 올바른 채널인지 확인(채널 ID·이름 조회)

시청자 정보, 댓글, 구독자 개인정보, 결제·수익 정보는 수집하지 않습니다.

2. 저장 및 보관

OAuth 인증 토큰과 업로드 기록(영상 ID, 제목, 업로드 일시)은 운영자 본인의 PC에만 저장되며, 외부 서버로 전송하거나 제3자에게 제공·판매하지 않습니다. 저장된 정보는 운영자가 언제든 삭제할 수 있습니다.

3. 권한 철회

Google 계정 → 보안 → 타사 앱 및 서비스(myaccount.google.com/permissions)에서 언제든지 본 도구의 접근 권한을 철회할 수 있습니다.

4. YouTube API 서비스

본 도구는 YouTube API 서비스를 사용합니다. 이용자는 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받습니다.

Privacy Policy (English)

Effective date: September 28, 2026 · Applies to "Creator Upload Manager" (the "Tool").

Data used. Through Google OAuth, the Tool uses only the youtube.upload scope (to upload videos and set their metadata) and the youtube.readonly scope (to confirm the connected channel's ID and name) for channels the operator has authorized. It does not collect viewer data, comments, subscriber personal data, or payment/revenue data.

Storage. OAuth tokens and upload records (video ID, title, upload time) are stored only on the operator's own computer. They are never sent to external servers, shared with, or sold to third parties, and can be deleted by the operator at any time.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.

YouTube API Services. The Tool uses YouTube API Services. By using it, you are bound by the YouTube Terms of Service, and the Google Privacy Policy applies.
